# 标签完整性审计

1. 官方论文的标签表可重建34类和46,686,579行，标签层级内部一致。
2. 每个攻击标签对应一次描述明确的攻击实验；这有利于标签来源解释，却不支持将同一细类拆成相互独立的训练、验证和测试活动。
3. Benign来自约16小时正常活动，但公开混合CSV仍未提供可用于分组的原始捕获/时间段ID。
4. 二级镜像探针只检出32类，缺少两个DDoS细类；其`random_3way`配置已经进行随机拆分，不能用于验证官方标签覆盖或正式泛化。
5. 本轮没有发现“标签完全随机”迹象：打乱标签后细分类Macro-F1降至0.029，接近32类随机参考0.031。但这只能证明特征与发布标签相关，不能证明相关性来自可泛化攻击行为。

结论：标签名称和粗细层级可用于工程开发；标签独立活动支持度不足，不能满足论文主数据集的监督与最终测试隔离要求。
