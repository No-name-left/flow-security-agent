# 泄漏与捷径审计

| 风险 | 结果 | 影响 |
| --- | --- | --- |
| 随机行划分 | 官方benchmark采用混合后80/20行划分 | 同一次攻击实验的相似窗口可跨训练和测试，不能作为本论文正式划分 |
| Spark分片冒充来源组 | 不允许 | `part-*`来自随机混合写出，不代表capture/run |
| 窗口长度编码类别族 | 明确存在 | `Number`几乎区分10包与100包家族；需消融但无法完全修复来源缺失 |
| 精确重复 | 小样本中跨partition有5个唯一特征向量重合，占验证唯一向量0.156% | 仅为二级镜像小样本，不能推断全库重复率 |
| 同特征多标签 | 小样本中8个特征向量对应多个标签 | 存在标签冲突或统计碰撞，正式清洗需保留报告 |
| IP/绝对时间/源文件捷径 | 无法审计 | 官方47字段不含可恢复的组标识；缺失不是“无风险”，而是无法建立独立分组 |
| 单特征捷径 | 未发现可独立完成细分类的单字段 | 最强单字段浅树Macro-F1约0.105；不排除多字段组合捷径 |

标签打乱测试回落随机说明探针代码没有显而易见的目标泄漏，但无法解决攻击活动跨集合的结构性泄漏。正式论文不得将官方随机拆分分数当作跨场景或开放集证据。
