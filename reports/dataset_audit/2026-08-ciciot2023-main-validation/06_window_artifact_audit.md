# 窗口构造伪影审计

## 发现

官方特征生成按攻击规模采用不同包数窗口：10包用于Benign和较小类别，100包用于DDoS、DoS和Mirai。二级探针中`Number`字段几乎完全复现这一规则：Benign、BruteForce、Recon、Spoofing和Web为10包的比例均为100%；DDoS、DoS、Mirai为100包的比例分别约99.95%、99.88%和99.83%。

## 探针

| 特征设置 | 细分类LightGBM Macro-F1 |
| --- | ---: |
| 39个可用字段 | 0.614 |
| 移除可用窗口统计字段 | 0.526 |
| 仅窗口统计字段 | 0.391 |
| 仅`Number` | 0.007 |

`Number`单独不能完成细分类，但它几乎编码粗类别的窗口生成策略；窗口统计字段整体提供了显著信号。因此高性能可能同时包含真实流量模式与数据构造策略，不能仅凭随机行基线判定跨场景有效。

## 使用约束

若后续保留工程实验，必须至少报告：移除`Number`、移除窗口构造敏感字段、粗细分类分开评价，以及外部/分组测试。没有来源组时，这些消融仍不能替代正式独立测试。
