# UWF低成本CPU信号与泄漏Probe

本探针固定种子`20260804`，使用scikit-learn 1.6.1、LightGBM 4.6.0；不使用GPU。所有模型特征排除了原始IP、绝对时间、UID、文件、周和版本。结果只用于数据Gate，不是论文正式指标。

## Task 2：Data24五类

Data24五个攻击周均含T1048/T1078/T1110/T1190/T1595。周级划分用前四周训练、2024-03-24周测试；每文件每类最多抽5,000条。测试周T1048仅23条，必须保留不稳定性警告。

| 模型/划分 | Macro-F1 | Micro-F1 | 说明 |
| --- | ---: | ---: | --- |
| Logistic Regression，随机行 | 0.8194 | 0.9306 | 行级基线。 |
| Logistic Regression，周留出 | 0.7414 | 0.9195 | 比随机下降0.0780。 |
| Logistic Regression，周留出且去端口 | 0.7149 | 0.8948 | 再下降0.0265。 |
| LightGBM，随机行 | 0.8360 | 0.9768 | 行级基线。 |

周留出LightGBM各类Recall为T1048 0.9565、T1078 0.9468、T1110 1.0000、T1190 1.0000、T1595 0.9778；去端口后分别为1.0000、0.9291、1.0000、1.0000、0.9474。由于T1048仅23条且多类由固定脚本产生，这些高值只能证明“存在可学习信号”，不能证明跨场景Technique识别已解决。

## 来源预测

LightGBM从稳定Flow特征预测UWF版本的Macro-F1为0.9386；删除端口后为0.7832。结论是：**grouped split下LightGBM仍然过强，但同时存在显著版本捷径。** 正式论文必须把跨版本、去端口和来源预测作为强制消融，并避免把本探针直接写成泛化结果。
