缓存最初只有6个spot-check文件；本轮从UWF官方目录补齐其余44个Parquet（约1.11 GB）及3个小型指标CSV，未超过8 GB上限。逐文件路径、字节数、行数、Schema与SHA-256见`uwf_file_inventory.csv`。

Data22与Fall22、Data24与Fall24-2、Sum25-1与Sum25-2存在日历周重叠。重叠不自动等于副本，但必须按家族和周审计；尤其Data22/Fall22已确认大规模逐行包含，不能重复计数。
